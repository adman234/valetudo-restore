Restore map

  

    Puts your saved map back — the floorplan, room divisions and room
    names. Valetudo, its settings and the voice pack are left alone, so use this
    when the map is missing but everything else is fine.
  


  

    
  


  
or restore from a specific archive:

  

    
    
  

  

    This must be a backup archive produced by this tool
    (valetudo-backup-….tar.gz). A bare data_map.tar.gz
    will not work — a map is five separate paths, not one folder.
  


  

    What this actually does
    

      A map is /data/ri + /data/map +
      /data/DivideMap (+ /data/DivideDebug,
      map_info.bin, mult_map.json). Restoring only
      /data/map produces a map ava rejects on the next
      boot — which is why a backup taken before this tool captured the full
      set is refused rather than half-applied.
    

    

      ava and miio_client are stopped, the files are
      swapped, and both are restarted. No reboot needed. Your
      previous map is moved to
      /data/_map_replaced-<timestamp> on the robot rather than
      deleted, so it can be put back by hand. /data/config/miio
      (wifi and device identity) and /mnt/private are never touched.
