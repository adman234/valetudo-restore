Restore from a specific archive

  

    Upload a backup archive and choose how much of it to put back. Use this for
    an older archive, or one kept outside this container. To restore from the
    newest full backup, use the buttons at the top.
  


  

    
    
    
  


  

    Restore everything puts back the lot: Valetudo, its
    settings (MQTT, schedules), the vendor settings (obstacle images, pet
    avoidance, carpet, mop), the voice pack, duststreamer, the boot hook
    and the map. Restore map only touches nothing but
    the map. Use it when Valetudo is fine and only the map is missing.
  

  

    The file must be a backup archive from this tool
    (valetudo-backup-….tar.gz). A bare data_map.tar.gz
    will not work, because a map is five separate paths, not one folder.
  


  

    What a map restore actually does
    

      A map is /data/ri + /data/map +
      /data/DivideMap (+ /data/DivideDebug,
      map_info.bin, mult_map.json). Restoring only
      /data/map produces a map ava rejects on the next
      boot, so an archive missing any of these is refused rather than
      half-applied. /data/DivideAI, which holds the detected floor
      material per room, is put back alongside it when the archive has it.
    

    

      ava and miio_client are stopped, the files are
      swapped, and both restart. No reboot needed. Your previous
      map is moved to /data/_map_replaced-<timestamp> rather
      than deleted. /data/config/miio (wifi and device identity) and
      /mnt/private are never touched.
