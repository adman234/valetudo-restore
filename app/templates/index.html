Restore map only

  

    Puts /data/map back without touching the Valetudo binary or its
    config. Useful after a wipe, since a full restore brings back Valetudo and
    its settings but leaves you needing a fresh mapping run.
  

  

    The map is not a JSON file. /data/map is a
    directory of binary SLAM data (app_map.bin,
    fine_large.bin) plus a few JSON descriptors, so upload a
    .tar.gz — either a whole backup archive from this tool, or
    the data_map.tar.gz extracted from one.
  

  

    
  

  

    
    
    
  

  

    The existing map is copied to /data/map.bak-<timestamp>
    first, so this is reversible. Reboot the robot afterwards —
    ava holds the map files open and will not pick up changes made
    underneath it. /mnt/private is never written.
